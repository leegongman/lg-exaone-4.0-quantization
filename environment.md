# Environment Notes

This file is not an install lockfile.

It is a reference environment note for the public documentation draft, not a
verified `pip install -r` requirements file. Package names below describe the
tool families used during the project and should be pinned only after the exact
reproducible environment is verified.

## Tool Families

- PyTorch
- Transformers
- Accelerate
- Datasets
- NumPy
- pandas
- tqdm
- vLLM
- lm-eval

## Reproducibility Status

Do not treat this file as a one-command setup path. Official competition
scoring, private evaluation behavior, checkpoint artifacts, and custom wheel
submissions are intentionally not reproducible from this clean public repo.
